# 三木点餐系统 · 本期需求

## 用户确认

- 仅在 Windows 使用。
- 主架构采用 Python，持久化使用 SQLite。
- 开发 / 测试阶段直接运行源码，提供后续 exe 打包方式。
- 主界面显示桌号，选择桌号及餐品下单。
- **只设置桌号数量，不设置每桌座位数。**
- 餐品与桌号配置永久保存在本地。
- 结算默认显示餐品总价，金额可修改；单独输入折扣，在下方显示最终价格。
- 结算必须确认。
- 需要用美团打印机打印结算单。
- GitHub 新建公开仓库，描述采用“自己写的点餐系统”含义。
- 收银台采用类似美团的黄黑布局，重新设计浅色样式，并支持深色模式。
- 桌台可以修改显示名称。
- 账单删除单项餐品不再二次确认；餐品管理也支持直接删除餐品。
- 新建数据库只提供 3 道示例餐品。
- 新增餐品时可从下拉框选择已有分类，或直接输入新分类。
- 新增收入统计，支持今日、选择日期、按月和按年查看收入。
- 历史订单增加状态下拉筛选；日期使用带日历的选择控件。
- 小票抬头居中，餐品名称在左，数量和价格在右；10 折不显示折扣，括号及其中的文字不显示。
- 系统设置支持上传自定义 Logo，软件左上角展示 Logo 与店名，小票最上方居中展示 Logo。
- 桌台、选择餐品、当前账单三个区域之间可用鼠标左右拖动分隔线调整宽度。
- 用餐中的桌台使用整块显著底色和状态文字，快速识别占用情况。
- 所有界面变化与后续改动必须同时适配浅色和深色模式。

## 实现约定

- 桌台内部编号连续，数量范围 1–200，显示名称可自定义。
- 同名分类复用；分类留空保存为“未分类”。本版允许点击新增创建同名餐品，各记录独立。
- 菜单删除为逻辑删除，旧订单保留关联和成交快照，界面提供最近一次菜单删除的撤销入口。
- 主题设置即时生效并入库；跟随系统模式响应 Windows 外观变化。
- 收银台分栏宽度在松开分隔线后保存，首次显示时恢复；双击分隔线恢复默认比例，各栏保留最小宽度。
- 卡片随可用宽度重新排列；用餐中卡片在选中时保留绿色底色，并用黄色边框表示当前桌台。
- 折扣以“折”为单位，10 为原价、8.5 为八五折，范围 0–10。
- 金额整数分入库，Decimal 计算折扣，最终实收四舍五入到分。
- 每次点餐操作立即保存；未结算订单在重启后恢复。
- 结算在事务内保存，并校验订单版本，防止重复结算或漏算另一实例加的餐品。
- 菜名、单价和结算小票保留快照；菜单修改不重写历史记录。
- 结算成功后异步打印；打印失败不撤销收款记录，可在历史账单补打。
- 收入按本机结算时间、最终实收统计，仅包含已结算订单；取消及未结算不计入，免单计入结算单数。
- 支持自选日期范围，包含首尾日期；年度按月汇总，其他方式按日汇总，明细可跳转到对应已结算账单。
- 历史订单支持单日、日期范围或不限日期，与全部状态、已结算、已取消组合查询。
- 小票采用餐品、数量、单价、金额四列，图形预览和打印共用排版；58 / 80 毫米纸宽按实际字宽换行。
- Logo 在上传时验证并缩小，按内容哈希存入 SQLite；图片随数据库备份保留，原文件移动不影响使用。
- 新订单保留店名、Logo、页脚、纸宽快照；旧版订单保留原始文本和金额，补打时使用新布局及当前 Logo。
- 数据库升级前自动备份；括号隐藏仅影响小票显示，不修改原始菜名、备注或订单。

## 尚待确认及现场验收

- 现有 Windows 驱动打印适配器是否兼容该设备；云专用机型需另接官方接口。
- 实体设备中文出纸、纸宽、走纸与切纸验收。
- 当前可从源码测试；本期提供打包脚本，未将 exe 作为已验收发行版发布。
